# 📉 Student Final Grade Prediction System

## 📌 Overview
An introductory predictive analytics project focused on forecasting student academic performance using machine learning. 

## ⚙️ Core Functionality
* **Data Preprocessing:** Implemented feature engineering, handling missing values, and categorical feature transformation using Label Encoding.
* **Model:** Developed a Linear Regression model using `scikit-learn` to predict final grade outcomes based on historical academic datasets.
* **Visualization:** Built a functional dashboard using `Streamlit` to allow users to input parameters and visualize predicted classifications.

## 🛠️ Technology Stack
* **Python** | **Streamlit** | **Scikit-Learn** | **Pandas**
